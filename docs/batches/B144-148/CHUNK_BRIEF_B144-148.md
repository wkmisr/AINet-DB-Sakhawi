## 実項/REF(転送見出し)判定の絶対基準（Waka裁定 2026-09-08、規則13で補強）
判定基準は「**その項自身に転送指示があるか**」のみ。
- **あり**（مضى/يأتي/هو الذي قبله/في ابن…/في محمد…/صوابه/فيمن جده…/فيمن لم يسم أبوه/فيمن اسم أبيه/فيمن أبوه/يأتي في الكنى/يأتي بزيادة/مضى في …/يأتي فيه/يأتي قريبا）→ **REF方式X**: `type="reference" subtype="LIMBO"`、ファイル名を `REF_` 接頭辞に変更、実伝由来要素（state/event/birth/death/affiliation/relation/nisbah 等）を除去、Pattern A の event は置かない、`<note type="reference" target="#AIND-Dxxxxx">` を付す。転送先が特定できなければ `target="#NEEDID"`。
- **なし**（名のみでも没年が食い違っても、**刊本の立項番号が無くても**）→ **二重立項型**: 両項とも実項のまま。同一人物の可能性が高ければ双方向 `possible_identity` + note（断定=cert high、أظنه 等=medium、ينظر=low）。
- 「له ذكر في …」型は本人の本伝であり **REF化禁止** = 実項 + relation。
- **「X اثنان : ابن … وابن …」型（同名2人の索引項）**: 転送動詞がないので **REF 化しない**。先例 `#AIND-D00404`・`#AIND-D05715`・`#AIND-D06026`・`#AIND-D06028` どおり、**実伝由来要素を持たない実項**とし、参照先2件を `<note type="editorial" xml:lang="ja">` に AIND 番号で記す。
- **転送先が2つある転送見出し**（D07073「فيمن جده عمر ... ومحمد」）: REF 方式X のまま、`target` には第1候補を書き、第2候補を `<note type="reference">` の本文（または editorial note）に AIND 番号で記す。
- REF にも `<note type="source" xml:lang="ar">` として原文を挿入（既存 `Individuals/0000-0999/REF_AIND-D00394_408502894922.xml` や `Individuals/6000-6999/REF_AIND-D06013_*.xml` を読んで真似る。note 順序は `source → translation(ja) → translation(en) → reference`。translation は残してよい）。

- **綴り相互参照型（「X . في Y」で Y が一人の人物ではなく同綴り見出し群を指すもの）＝確定（Waka 裁定 2026-10-26 B134-138 ★1 (a)、v13.44 追記 (g)）**: REF 方式X、`<note type="reference" target="#NEEDID">`、`<note type="editorial" xml:lang="ja">` に「綴りの相互参照。見出し群『Y』（AIND 番号を列挙）を指し、特定の一人を指さない」。見出し群が corpus でちょうど1件ならその AIND を target に書く。先例 `REF_AIND-D02818`・`D06354`・`D06368`・`D06369`（B134-138）。

## 標準規則（要点）
- 第三者言及（ذكره/أرخه/قال فيه/ترجمه/أثنى عليه/أفادنيه/بيض له/حكى/وصفه/كتب عنه）は `event type="cultural" subtype="mention"` + persName ref（Pattern A、逆relation不要）。一人称主体は `wd:Q4120128`、شيخنا=Ibn Ḥajar（`wd:Q471116`）。
- persName full に居住句・職名句・父の述語を入れない。他人の職を state にしない。原文にない属性（没地・居住地・学派・生年）は付けない。
- cert 3段階: قال أنه・بلغني・أظنه・ظنا=medium ／ زعم=low ／ يحرر・ينظر=low+possible_identity。逆算生年は「頃・cert low・逆算を note に明記」で可。**一の位しか書かれていない年（「سنة ثلاث」「سنة خمس」「سنة تسع」「سنة إحدى」）は基本的に 80X、cert medium**（2026-09-24 Waka）＝先例 D07006（801）・D07036（805）・D07084（805）・D07072（801）・D07107（809）・D07024（809）・D06109（807）。文脈で 90X が確実なら 90X（note）。位脱落「سنة وتسعين」=890 cert medium。
- **「باسمه … من مرتبات」型（名義上の俸給保持）は `state type="status"`**。
- **「سمع على／قرأ على」の直後に人名が来ない場合は「عليّ（私＝サハーウィーに）」と読む**。
- **「ولد」の直後に年号が続かず幼少者の描写が続く場合は「ولدٌ（幼い子）」**。
- 綴り揺れ同定（الكرماني=الكيلاني 等）は根拠を note に埋め込み名寄せしない。relation の desc は相手の名前のみ（根拠句は note）。片方向で十分（鏡像不要）。
- ID桁数: AIND-D=5桁 / TMP-P=6桁 / その他TMP=5桁。`xml:lang="lat"` は使わず `"ar-Latn"`。`<desc>` には必ず `xml:lang`。
- 翻訳(ja/en)は原文と逐語二重照合。hedge を落とさない。翻字・内部ID・立項連番・推測句を訳文に残さない。
