## 実項/REF(転送見出し)判定の絶対基準（Waka裁定 2026-09-08）
判定基準は「**その項自身に転送指示があるか**」のみ。
- **あり**（مضى/يأتي/هو الذي قبله/في محمد/صوابه/فيمن جده…/فيمن لم يسم أبوه/فيمن اسم أبيه/يأتي بزيادة）→ **REF方式X**: `type="reference" subtype="LIMBO"`、ファイル名を `REF_` 接頭辞に変更、実伝由来要素（state/event 等）を除去、Pattern A の event は置かない、`<note type="reference" target="#AIND-Dxxxxx">` を付す。転送先が特定できなければ `target="#NEEDID"`。
- **なし**（名のみでも没年が食い違っても）→ **二重立項型**: 両項とも実項のまま。同一人物の可能性が高ければ双方向 `possible_identity` + note（断定=cert high、أظنه 等=medium）。片側だけREF化するのは不可。
- 「له ذكر في …」型は本人の本伝であり **REF化禁止** = 実項 + relation。
- REF にも `<note type="source" xml:lang="ar">` として原文を挿入する（既存 `Individuals/REF_*.xml` を1件読んで真似ること）。

## 統一規則（HANDOVER v13.28。前回バッチでチャンク間の方針割れが起きた箇所）
1. relation の `@n` は**要素単位（`<relation>` 全体）の出現順通し番号**。subtype ごとではない。
2. 「ممن سمع مني بـX」型: teacher relation（method سمع）＋ relation 内 event。field（الحديث）は付けない。
3. 父の relation: 祖父名まで復元できれば TMP-P、corpus に本伝があれば AIND、裸名のみ／一族ニスバのみは `#NEEDID` 維持。
4. 「قريب الN」型は年表現（`when-custom=N`、cert low/medium）。「بعد／قبل／بضع」のみ notBefore/notAfter。
5. persName `name_only` は3世代、`full` は職名句・居住句を除く。
6. 転写は「イブン・ファハド」式。
7. Pattern A の desc は言及句のみ、判断句は note へ。
8. affiliation と state の二重符号化禁止（同一施設を両方に書かない。職名は state 側に残し affiliation 側は作らない）。
9. **日付は必ず独立に再計算して検証**（前バッチで最多の是正項目＝Hijri→Gregorian 変換ミス6件。年境界＝月初/月末/年初/年末に近い日付は特に注意）。tabular Islamic: `jd=(11y+3)//30+354y+30m-(m-1)//2+d+1948440-385`、曜日で検算。
10. **新規TMP発行前に corpus 全体検索を徹底**（6代ナサブ完全一致の既存実項を見落として新規発行しかけた事例あり。下の「頻出確定ID」に載っている人物の見落としも複数発生）。
11. **複数人物の合同索引項目**（例「ابن الحاجب: عبد الرحيم وأمير علي وعمر بنو…」のように3人以上を束ねた AIND-D 項目）は relation の active/passive に直接充当してはならない（「個人に対応できるのは個人のみ」）。新規 TMP-P を発行して対応。
12. 識別要素（固有名＋ラカブ/ニスバ/クンヤ/職名等）があれば、既存候補との同定に確信が持てなくても**新規 TMP-P 等を発行する**。`#NEEDID` は「完全に無名」「裸の汎用名のみ」に限定。

## 標準規則（要点）
- 第三者言及（ذكره/أرخه/قال فيه/ترجمه/أثنى عليه/أفادنيه/بيض له/حكى/وصفه）は `event type="cultural" subtype="mention"` + persName ref（Pattern A、逆relation不要）。active=teacher・passive=student。一人称主体は `wd:Q4120128`、شيخنا=Ibn Ḥajar（`wd:Q471116`）。
- `@when` は西暦のみ（ヒジュラは `when-custom`、4桁ゼロ詰め）。年のみ表記は年初、月のみは月初、`notAfter` は年精度なら年末。「منتصف/أوائل/حدود」は日付語でない。
- persName full に居住句・職名句・父の述語を入れない。原文にない属性（没地・居住地・学派・生年）は付けない。他人の職を state にしない。
- cert 3段階: قال أنه・بلغني・أظنه=medium ／ زعم=low ／ يحرر・ينظر=low+possible_identity。
- 逆算生年は「頃・cert low・逆算を note に明記」で可。
- ID桁数: AIND-D=5桁 / TMP-P=6桁 / その他TMP(N/L/I/O/T/S)=5桁。`xml:lang="lat"` は使わず `"ar-Latn"`。`<desc>` には必ず `xml:lang`。
- 翻訳(ja/en)は原文と逐語二重照合。伝聞・自称の hedge を落とさない。翻字・内部ID・立項連番・推測句を訳文に残さない。
- **原文全文の `<note type="source" xml:lang="ar">` を `<note type="translation">` の直前に入れる**（既存ファイルに倣う。本バッチの初版には無い可能性が高い＝要挿入）。
- **初版作成者の `<respStmt>` は改変しない**。自分の校閲は新しい `<respStmt>`（`resp`=「校閲」、`persName`=あなたの識別子 例 `claude-b86-review-1`、`date when="2026-09-18"`）を追加して記録する。
