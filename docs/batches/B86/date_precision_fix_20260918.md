## 6. AIND-D00629 — `notBefore`/`notAfter` 化

原文「مات في سنة ست أو سبع وثلاثين」＝没年は **AH 836 または 837**。

再計算（グレゴリオ暦・本パスで独立に検証済み）:

- AH 836 初日 = **1432-09-06**（AH 836 末日 = 1433-08-26）
- AH 837 初日 = 1433-08-27、AH 837 末日 = **1434-08-15**

ヒジュラ暦の範囲は **AH 836-01-01 〜 AH 837-12-29**、
グレゴリオ暦では **1432-09-06 〜 1434-08-15** で、西暦 **1432・1433・1434 の3年**にまたがる。
したがって単一の `@when` はどの精度でも「その年に没した」という偽の断定になるため**廃止した**。
旧値 `@when="1500-03"` は約68年ずれた明白な誤りであり、
`@when-custom="0836-837"` も `YYYY-MM` と誤読されうる非標準表記であった。

置換後:

```xml
<death notBefore-custom="0836" notAfter-custom="0837" notBefore="1432" notAfter="1434" cert="high">
```

書式は `Individuals/` 既存の範囲表記に倣った（`notBefore-custom` を含む49ファイルを確認）。
年精度のヒジュラ範囲には**年精度の西暦**を与えるのが当リポジトリの一貫した慣行であり、
既存例 `0809`/`0810`→`1406`/`1408`、`0833`/`0839`→`1429`/`1436`、
`0843`/`0849`→`1439`/`1446`、`0831`/`0839`→`1427`/`1436` はいずれも
§1 の年精度規約（`notBefore`＝元日の年、`notAfter`＝末日の年）どおりに再現できた。
ヒジュラ値が支持しない日精度（1432-09-06 / 1434-08-15）は属性には入れず、**note に記録**した。

**未変更のまま残した点**: `cert="high"` は範囲が2年にわたる以上見直しが望ましいが、
今回の裁定は暦表現の是正のみを承認したものと解し、触れていない（要別途判断）。
