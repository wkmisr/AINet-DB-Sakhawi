## 3. 非標準 `@when-custom` 4件の個別点検

### AIND-D00629 — `@when-custom="0836-837"` / `@when="1500-03"` → **未編集（要判断）**

原文は「مات في سنة ست أو سبع وثلاثين」＝没年は **AH 836 または 837**。既存の `@when="1500-03"` は
ユリウス暦・グレゴリオ暦のいずれでも誤り（AH 836 ≒ 1432 CE で、約68年ずれている）。

グレゴリオ暦での境界を再計算すると:

- AH 836 初日 = **1432-09-06**、AH 836 末日 = 1433-08-26
- AH 837 初日 = 1433-08-27、AH 837 末日 = **1434-08-15**

したがって真の範囲は **1432-09-06 〜 1434-08-15** で、西暦 **1432・1433・1434 の3年**にまたがる。
単一の `@when` はいずれの精度でも「その年に没した」という偽の断定になるため、
**健全な単一値は存在しない**と判断し、本ファイルは編集していない。

（補足: 1433年は全日が AH 836–837 の範囲内に収まる唯一の西暦年だが、
没年が 1432年9〜12月 または 1434年1〜8月 である可能性を排除できないため `@when="1433"` も不可。）

**推奨する是正**（構造変更を伴うため裁定を請う）: `@when` を廃し
`notBefore-custom="0836" notAfter-custom="0837" notBefore="1432-09-06" notAfter="1434-08-15"` とする。
あわせて `@when-custom` の非標準表記 `0836-837`（`YYYY-MM` と誤読されうる）の正規化も必要。
現在の `cert="high"` も範囲が2年にわたる以上、見直しが望ましい。
