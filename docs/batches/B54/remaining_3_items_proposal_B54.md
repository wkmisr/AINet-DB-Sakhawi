# ② `زعم` / `بلغني` / `قال أنه` / `يحرر` の cert 運用 ← **方針決定をお願いします**

## 問題の所在

原文が明確に伝聞・自称・留保を示しているのに、**構造化データが断定として記録されている**問題です。
**訳文側は3件とも正しく訳出されており、XMLだけが情報を落としています。**

| ファイル | 原文 | 現在の記録 |
|---|---|---|
| `D05666` | وكذا **زعم** الشهاب ابن أسد أنه قرأ عليه | teacher relation（cert なし） |
| `D05704` | و**بلغني** أنه ممن يدرس الفقه ويتكسب بالشهادة … وحج | state ×2 ＋ event（cert なし） |
| `D05705` | و**قال أنه** سمع البخاري على … وبعض مسلم على … والشفا على … | teacher relation **×4**（cert なし） |
| `D05634` | **يحرر** أهو من ترجمة هذا | 死亡noteの英文に埋没・構造化なし |

## 提案する規則

**「誰が主張しているか」で3段階に分ける**案です。B44-48の「يحرر＝possible_identity cert=low」を出発点に拡張します。

| マーカー | 言表の主体 | 提案 cert | 付与先 |
|---|---|---|---|
| （マーカーなし） | **サハーウィー自身の直接叙述** | **付与しない** | — |
| `قال أنه` / `ذكر أنه` | **伝主本人の自称**（サハーウィーは中立に報告） | **`cert="medium"`** | 当該 relation / state |
| `بلغني` / `أُخبرت` | **サハーウィーへの伝聞**（情報源を明示しない） | **`cert="medium"`** | 当該 relation / state |
| `زعم` | **第三者の主張＋サハーウィーの留保** | **`cert="low"`** | 当該 relation |
| `يحرر` | **サハーウィー自身が未確定と明示** | **`cert="low"`** ＋ `possible_identity` | B44-48前例どおり |

### `زعم` を1段下げる理由

`قال` / `بلغني` が中立の報告動詞であるのに対し、**`زعم` はアラビア語の史書叙述において「主張した（が疑わしい）」という留保を伴う**のが通例です。
サハーウィーが `قال` ではなく `زعم` を選んだこと自体が評価的な行為であり、これを `قال` と同列に扱うと**サハーウィーの判断が失われます**。
【サハーウィーの伝記作成術】の観点からも、この使い分けは保存する価値があります。

### 併せて提案

1. **マーカー語そのものを `<note>` に残す**（例: `<note xml:lang="ar">زعم</note>`）。後から根拠を追跡でき、方針変更時の再処理も可能になります。
2. **precheck v12 に検出を実装**: corpus本文に `زعم|بلغني|قال أنه|ذكر أنه|يحرر` があるのに、対応する relation / state に `cert` がない場合を警告。

## ご判断いただきたいこと

- **(a) 上記3段階案でよいか**（`زعم`=low / `قال`・`بلغني`=medium / `يحرر`=low+possible_identity）
- **(b) すべて `cert="low"` に統一するか**（運用は単純だが、サハーウィーの語選択の差が消えます）
- **(c) その他**

ご決定いただければ、上記4ファイルに即適用します。
