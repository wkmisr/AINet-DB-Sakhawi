## 実項/REF(転送見出し)判定の絶対基準(Waka裁定 2026-09-08)
判定基準は「**その項自身に転送指示があるか**」のみ。
- **あり**(مضى/يأتي/هو الذي قبله/في محمد/صوابه/فيمن جده…/فيمن لم يسم أبوه/فيمن اسم أبيه/يأتي بزيادة/هكذا قرأته بخط بعضهم وقد مضى…)→ **REF方式X**: `type="reference" subtype="LIMBO"`、ファイル名を `REF_` 接頭辞に変更、実伝由来要素(state/event等)を除去、Pattern A の event は置かない、`<note type="reference" target="#AIND-Dxxxxx">` を付す。転送先IDが今回のバッチ内・既存repo内で特定できなければ `target="#NEEDID"` とする。
- **なし**(名のみでも没年が食い違っても)→ **二重立項型**: 両項とも実項のまま。もし同一人物の可能性が高ければ双方向 `possible_identity` の relation と note を付す(サハーウィー本人が断定していれば cert=high、"أظنه"等の推量なら cert=medium)。片側だけをREF化するのは情報を失うため不可。
- 「له ذكر في …」型(本人の別項参照)は本伝であり **REF化禁止** = 実項 + relation。
- REF にも `<note type="source" xml:lang="ar">` として原文を挿入すること(方式は既存 Individuals ファイルを1件 read して真似ること)。

## TMP発行ルール
- 名前に識別要素(ナサブ・ニスバ・ラカブ・クンヤ・職名)があれば立項がなくても TMP-P を発行する。
- 本文で裸名でも本項主のナサブから祖父名まで復元できる近親(父を同じくする兄弟等)は TMP-P を発行する。
- 祖父名まで復元できない父・一族ニスバのみ継承の復元形(例:「أحمد الجزيري الرابطي」型)は発行せず `#NEEDID` を維持する。
- `#NEEDID` の維持は「名不詳・裸の汎用名・既存項間で曖昧」な場合に限る。名不詳者の `#NEEDID` relation は削除しない。
- TMP発行前に corpus に当該人物が実在するか確認必須。

## 標準規則(要点)
- 第三者言及(ذكره/أرخه/قال فيه/ترجمه/أثنى عليه/أفادنيه/بيض له/حكى/وصفه)は `event type="cultural" subtype="mention"` + persName ref(Pattern A、逆relation不要)。active=teacher・passive=student。一人称主体は wd:Q4120128、شيخنا=Ibn Ḥajar(wd:Q471116)。
- `@when` は西暦のみ(ヒジュラは `when-custom`)。年のみ表記は年初、月のみは月初。`notAfter` は年精度なら年末年。`بعد/قبل/بضع` は `notBefore`/`notAfter-custom`。「منتصف/أوائل/حدود」は日付語でない(年精度扱い)。「أواخر سنة N」は年初換算とズレるため要注意。
- persName full に居住句・職名句・父の述語を入れない。原文にない属性(没地・居住地・学派・生年)は付けない。他人の職を state にしない。
- relation の `n` は要素種別ごとの通し番号。片方向で十分(鏡像relation不要)。desc は相手の名前のみ(根拠句は note に)。
- cert 3段階: قال أنه・بلغني・أظنه=medium / زعم=low / يحرر・ينظر=low+possible_identity。
- 裸名の親族は `#NEEDID` relation を維持(削除しない)。ナサブ付きの父は TMP-P を発行。
- 逆算生年は「頃・cert low・逆算をnoteに明記」で可。
- 翻訳(ja/en)は原文と逐語二重照合。伝聞・自称の hedge(「〜という」「自称」等)を訳文で落とさない。
- 転写(ラテン翻字)や内部ID・立項連番・推測句を訳文に残さない(precheckで「連番訳混入」が出た箇所は特に確認)。
- AIND人物のWikidataは `<person corresp="wd:Q…">`。
- 初版作成者の respStmt は改変しないこと(機械検証対象)。あなたの校閲作業は新しい `<respStmt>` を追加する形で記録する(`resp`=「校閲」、persName=あなたの識別子、date=作業日)。
