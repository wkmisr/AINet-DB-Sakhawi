### ★1 綴り相互参照型の転送見出し（§D135-4・§D137-5・§D138-3）
- **状況**: 「X . في Y」で Y が一人ではなく同綴り見出し群を指す4件（D02818 خاير بك→خير بك 10項、D06354 قطلبك→قطلو بك 3項、D06368 قنباك→قانبك 3項、D06369 قنباي→قانباي 21項）。repo に先例なし。暫定で REF 方式X（`type="reference" subtype="LIMBO"`、`<note type="reference" target="#NEEDID">`）とし、書式を4件で統一した（reference note は一文、列挙は editorial note のみ）。
- **選択肢**: (a) 現状（REF 方式X＋target #NEEDID＋editorial 列挙）で確定／(b) REF のまま `subtype="orthographic"` 等の別 subtype を設け、target に見出し群の先頭 AIND を書く／(c) 個人 DB の対象外として収録しない（ID-Master に見出し語だけ記録）。
- **推奨: (a)**。実項/REF 判定の絶対基準（2026-09-08、転送指示があれば REF）にそのまま乗り、新しい語彙を増やさない。target=#NEEDID は「特定の一人を指さない」ことの正しい表現で、列挙は editorial note に残るので情報は失われない。見出し群がちょうど1件なら target にその AIND を書く（ブリーフ既定）を細則に明記する。(b) は統制語彙を増やすわりに検索上の利点が小さい。

### ★2 「صهر X」「صاهر X」で向きが決まらない姻戚の符号化（§D138-2）
- **状況**: D06361「وصهر ابن حمام」（#NEEDID、cert low）、D06365「صهر الجمال يوسف بن تغرى بردى」（#AIND-D10460、cert medium。本項主は約807年生で相手（813年生）より年長＝姉妹の夫の可能性もある）、D06372「فصاهر البدر بن مكتوم」（TMP-P-NEW138-03、cert medium）。いずれも暫定で `father-in-law`（相手＝妻の父）とした（repo 先例 D02131「صهر يشبك الفقيه」→ father-in-law cert medium）。repo は「صاهره X على ابنته」→ son-in-law（D05502）、「على أخته」→ brother-in-law（D04221・D04209）と、前置詞句があるときだけ向きを決めている。訳文は「姻戚」「related by marriage」に直した。
- **選択肢**: (a) 現状（father-in-law を既定とし cert で不確かさを表す）／(b) 向きが原文で決まらない場合は統制語彙 `relative`（repo 既存）＋note「صهر（向き不明）」にする／(c) 新 subtype `in-law` を設ける。
- **推奨: (b)**。father-in-law は「相手が妻の父」という具体的な主張で、cert medium でも向きの誤りを含みうる（D06365 は年齢から逆の可能性が高い）。`relative` は repo 既存語彙で新設が要らず、前置詞句（على ابنته／أخته）や年齢で向きが決まる場合だけ father-in-law・son-in-law・brother-in-law を使う、と細則化できる。採用なら本バッチ3件（D06361・D06365・D06372）と repo D02131 を `relative` に付け替える。決定までは (a)。
