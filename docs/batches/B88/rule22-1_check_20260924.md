## 2. スキャン方法と前回実測（397件）との差

- 各ファイルの `<note type="source" xml:lang="ar">` と各 ar placeName を正規化（U+064B〜U+0652・U+0640・U+0670 除去、أإآٱ→ا、ى→ي、ة→ه、空白圧縮）して突合。
- 照合は**語単位**: 前接辞 `[وفبلك]{0,2}` と冠詞 `ال`／`ل` を許し、前後がアラビア文字でないこと（語境界）を要求。定冠詞の有無は両方許容。
- 前回（2026-09-21）の 397 件は**部分文字列**照合とみられる（同法で再計算すると 398 件）。部分文字列照合では `مصر` が `المصري` の中に、`دمشق` が `الدمشقي` の中に「現れる」と判定され、**ニスバの中にしか地名がない＝まさに第1項の対象**が 87 件漏れる。今回は語単位照合の 485 件を母数とした。
- 機械照合で「現れない」と出たものの中には、原文の異綴・語形変化（`بمعلاتها`、`توريز`、`بائشام`、`الينبوع`、`نوا`、`بالغرية` 等）が含まれるため、全 485 件を 1 件ずつ原文と要素を読んで分類した（C はこの種）。

## 3. 分類基準（今回の運用）

- **A**: 地を受ける代名詞・照応語が原文にあり、その地を受けているもの。`بها／فيها／به／منها／قاضيها／خطيبها／جامعها／أحد عدولها／قطنها` 等。先行詞がニスバのみのものを含む（規則22-3）。照応副詞 `هناك` で先行詞が حج（#11, #13, #39）またはニスバ（#263）・`بها`（#290, #324）のものも A とした。先行詞が `بلده` である `ها`（#116, #297, #298, #352）も A。
- **B**: `event subtype="hajj"` の `مكة`。
- **C**: 原文に地名・施設名の根拠がある語形展開。`بمعلاتها`→المعلاة、異綴（`توريز`／`الينبوع`／`نوا`／`القدس`→بيت المقدس）、誤植（`بائشام`、`بالغرية`）、施設名の展開（`البرقوقية`→المدرسة البرقوقية、`الحرم المكي`・`الجامع المصري`・`جامع المقسي` のような地名を含む複合語）、**ニスバ＋限定語で原文自身が当該イベントの地を明示するもの**（`الحسيني سكنا`→居住、`القاهري المولد والدار`→出生・居住、`النابلسي المولد`、`الغزي الدار`、`المصري سكنا`、`الدمشقي الأصل`→出自イベント）、`بالديار المصرية`→مصر。
  - 限定語とイベントが一致しないもの（`الطرابلسي الأصل` から出生地、`المصري الأصل` から居住）は D とした。
- **D**: 代名詞も語義的根拠もない補完。ニスバのみ／施設（モスク・マドラサ・ハーンカー・墓地・市場・`المسجد الحرام`・`الحرم النبوي` 等）の所在地／職の勤務地／師・サハーウィー・スルタンの所在（`سمع مني`、`بمنزلي`、`بمجلس شيخنا`）／`جاور`・サハーウィー自身の `مجاورة`（規則20）。
- **E**: 上記で割り切れない境界例。除去せず §5 に一覧化。

## 6. 付随して気づいた点（本点検では未変更）

- `AIND-D01681`: 原文は「مات … خارج مكة」だが death の placeName が裸の `مكة`。D02926・D03301 は `خارج مكة` の文字列で gn:104515 を参照し note で限定する §4-17 方式、D02328 は placeName を立てず note のみ。表記の統一が必要か。

- 除去の結果、placeName を 1 つも持たなくなった要素は 209 個（event/residence 87、state/office 57、event/learning 19、event/residence/jāwara 15、death 7、event/political 5、その他 19）。指示どおり要素は残したが、とくに**ニスバだけから立てられていた居住イベント 87 件は、地を失うと中身が note のみ**になる（例 `AIND-D00060`・`AIND-D00824`）。こうした空の居住イベントを残すか削るかは別途方針が要る。
