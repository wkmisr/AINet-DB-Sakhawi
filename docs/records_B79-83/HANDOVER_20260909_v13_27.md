## 統一規則（チャンク並行時に必ずブリーフへ転記）
1. relation の `@n` は **要素単位（`<relation>` 全体）の出現順通し番号**。subtype ごとではない。event・state もそれぞれ要素単位。
2. 「ممن سمع مني بـX」型: teacher relation（method سمع）＋ relation 内 `<event type="learning"><placeName/><desc>原文句</desc></event>`。**field（الحديث）は付けない**（原文に学科名がないため）。独立の `<event type="study">` は置かない。訳に「（ハディースを）」を補わない。
3. **父の relation（規約5・§D-3・§D-9）**: 見出しナサブから父のナサブ（父の父＝伝主の祖父）まで復元できれば TMP-P（例 علي بن سليمان بن عثمان الجبرتي → 父 سليمان بن عثمان الجبرتي）。corpus 本伝があれば AIND（原文に関係記述がなくても見出しナサブ一致で可、cert は付けない）。裸名＋一族ニスバのみ（صلاح الغزي）・裸名のみ（حيدر）は `#NEEDID` relation を**維持**（削除しない）。
4. 「قريب الN」「سنة N أو قريبا منها」は年表現 → **when-custom=N、cert low（قريب）／medium（أو قريبا منها）**。「بعد／قبل／بضع」だけが notBefore/notAfter 方式。原文にない幅（±2年）を作らない。
5. persName name_only は repo 慣行（名＋父＋祖父の3世代）。full は見出しの名〜ニスバ（職名句・居住句を除く。家系呼称の一部と読める「الخطيب أبو الحسن بن درباس」型は保持し notes に明記）。
6. 転写: 「イブン・ファハド」（ファフド不可）。「ビン／ブン」は repo で混在＝当面統一しない。
7. Pattern A の desc は言及句のみ（サハーウィーの判断句「والظاهر أنه غير …」は note へ）。death の `<note xml:lang="ar">` は没記述までで切り、「أرخه …」は含めない。
8. 同一事実を affiliation と state で二重に符号化しない（機関は state 内 orgName に一本化）。ニスバ由来の affiliation（الأزهري → الأزهر）も residence と同様に不可。
