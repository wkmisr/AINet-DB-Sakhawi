## 教訓（規則へ）
- 名寄せの対象は「登録名」ではなく「使用箇所の原文の呼び方」。登録名が原文より詳しいときは原文の形に戻して判定する（ابن شداد・المنير・ابن الجزري）。
- 同家に同じ呼び名の人（父子・祖父孫・叔父甥）がいないかを、名寄せの前に必ず引く。
- 名寄せは番号を一括で付け替えるため、初版の番号誤記（D00272）がそのまま別人へ移る。付替え時に各箇所の原文に相手の名があるかを確かめる。
