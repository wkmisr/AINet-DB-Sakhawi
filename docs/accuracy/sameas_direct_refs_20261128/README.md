# same_as にある番号への直接の参照を AIND 番号に付け替え（2026-11-28）

WK 裁定 2026-11-28（「付け替えを進めてください」）。作業は Claude Fable 5.2。PR #132（corresp を外し same_as に一本化）と #133（台帳の作り直し）の続き。

## 経緯

#133 で台帳を作り直したところ、本伝があり典拠表の same_as に Wikidata 番号を入れた 4人について、レコードが ref・active・passive に Wikidata 番号そのものを書いて直接指している箇所が 20 残っていた。#132 は corresp 属性だけを対象にしたので、ここは手付かずだった。「AIND 番号を正とする」「外部 ID は same_as 欄にだけ持つ」に合わせ、AIND 番号に付け替えた。

計 20か所・14 レコード。各レコードに respStmt を足した。一覧は `changes.tsv`。変えたのは属性の値と respStmt だけで、注の文章にある「wd:Q…」の記述（履歴）は変えていない。

`tools/authority/build_authority.py` の `check` に検査を足した：典拠表の same_as にある番号を、レコードが ref・active・passive で直接指していないこと。

- 14 レコードの差分は、属性の値 20か所と respStmt 14個だけ。XML として読める。

- `build_authority.py check` は終了コード 0。
