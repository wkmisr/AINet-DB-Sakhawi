# 官職 ID の整理（2026-11-16、Waka 裁定）

## 背景
LLM 抽出の評価で、官職の不一致 81 件のうち 31 件が ID の付け方の不統一（同じ職に複数の ID、ID の流用）によるものだった。
これを機に repo 全体（官職の state 2,251 件、ID-Master の官職 ID 398 件）を点検した。

## 方針（Waka 裁定）
1. 職業・生業も官職と同じ `state type="office"`。区別は ID-Master の新しい「分類」列で持つ（8 分類）。
   صوفي・فقيه 等の学識・宗教的身分も、中世の文脈では俸給職との境界が曖昧なので state のまま。
2. 制度上の官職名は固有 ID。汎用の職に場所・施設が付いただけのものは汎用 ID＋placeName/orgName（職位は組で識別）。
3. 包括語 TMP-O-00002（غيرها）は廃止。
4. ID の流用は是正。
（CHUNK_BRIEF 規則65 として明文化）
