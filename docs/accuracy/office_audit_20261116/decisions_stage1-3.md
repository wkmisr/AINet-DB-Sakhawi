## ★1 نائب القاضي（TMP-O-00003、49 記録）／نائب الحكم（TMP-O-00096、27 記録）

**同じ職。** 原文は「ناب في القضاء」と「ناب في الحكم」を区別なく使い、どちらの ID に入ったかは表記しだい。
- 00003: D00935「آخر من ناب في القضاء بدمشق」、D01958「وأفتى وناب في الحكم」（←「الحكم」なのに 00003）、D05902「أحد نواب الشافعية بدمشق」
- 00096: D02003「نائب الحكم بدمشق」、D07623「ناب في القضاء」（←「القضاء」なのに 00096）、D07866「أحد نواب المالكية」
- **先例: Waka 裁定 2026-07-11**（ID-Master 00096 の Note）「コーパス固有の正規語。今後の裁判代理官は本 ID（00096）へ一本化」。そのとき 00003 は「コーパス出現ゼロの legacy 登録」だったが、その後のバッチで名前の一致から 00003 が付き続けた。

- **(a) 推奨**: 00003 を 00096 に統合（49 記録を付け替え、ID-Master 00003 は retired、00096 の Arabic に「نائب القاضي | نائب القضاء」を別名として足す）。2026-07-11 の裁定どおり。
- (b) 逆に 00096 を 00003 に統合（記録数は 00003 が多い）。

## ★2 مدرس（TMP-O-00036、18 記録）／تدريس（wd:Q352842、29 記録）

**同じ職**（行為者名詞と動名詞の違いだけ）。どちらも施設は orgName で示している（例: 00036 D04649「مدرس الجوهرية بدمشق」、Q352842 D07926「ولي تدريس الأيتمشية والأبو بكرية」）。

- **(a) 推奨**: 00036 を wd:Q352842 に統合（規則65 の「汎用 ID＋場所・施設」に合う。wd を優先）。
- (b) 両方残し、区別の基準を決める（区別できる基準は見つからなかった）。

付記（裁定不要なら現状維持）: 両 ID には、職に就いたというより「教えた」だけの記述も入っている（D07974「كان يتعانى التدريس في الفقه」、D05704「ممن يدرس الفقه」、D07171「ودرس」）。2026-11-16 の裁定（صوفي・فقيه は state のまま）に合わせ、state のまま残す案で進める。

## ★3 مشيخة التصوف／مشيخة الصوفية（TMP-O-00077、5 記録）／شيخ صوفية（TMP-O-00170、3 記録）

用例は二種類に分かれる。
- **施設の職**: D00438「نصف مشيخة التصوف بالصلاحية」、D00443「مشيخة الصوفية بتربة الأشرف اينال」、D03528「مشيخة الصوفية بالجامع الجديد بمصر」、D02853「مشيخة سعيد السعداء」、D02991「شيخ صوفية المكان الذي بناه الجمالي」
- **施設に属さない**: D08924a「شيخ المتصوفة المنسوبين للطائفة القادرية」、D10273「(الطاووسي) وصفه بالإرشاد وأنه شيخ الصوفية」、D07103「شيخ الصوفية الآن بزبيد」

PR #108 の独立校閲で、ハーンカーのマシュヤハ（D07144・D08902a「مشيخة الخانقاه الناصرية بسرياقوس」）は **wd:Q7492880＋orgName** にそろえた。D02853「مشيخة سعيد السعداء」は同じ型なのに 00077 に残っている。

- **(a) 推奨**: 施設の職（5 記録）は wd:Q7492880＋orgName に。施設に属さない 3 記録は 00170 を 00077 に統合し、00077 を「شيخ الصوفية | مشيخة الصوفية（施設に属さない長・称号）」に改める。
- (b) 00170 を 00077 に統合するだけ（施設の職も 00077 のまま）。この場合、サルヤークースなど Q7492880 に入れたハーンカーのマシュヤハとの不揃いが残る。

- (b) 統合だけ行い、付け替えはしない。

## ★6 代理職の扱い

いまは二つの書き方が混在している。
- **代理専用の ID がある**: نائب الحكم（00096）、نائب كاتب السر（00244、3）、نائب الإمام（00285、5。PR #108 で汎用 ID にした）、نائب الحسبة（00207、3）、نائب شيخ الخدام بالحرم المدني（00318、1）、نائب رأس نوبة الجمدارية（00125、1）
- **本職の ID のまま**（ラベルにだけ「نائب／نيابة」）: 12 記録
  - D10087「ناب في القضاء والإمامة بمكة」・D03724「ناب في امامة الحنفية بمكة」・D02659「وأم بالبرقوقية نيابة」→ Q125482 الإمامة（00285 があるのに）
  - D02706「نائب ناظر البيمارستان」・D07647「نيابة النظر بالبيمارستان」→ 00032 ناظر
  - D05973「ناب عن ابن عمه العلاء في نظر الجيش」→ 00045 نظر الجيش
  - D05985「النقابة نيابة」→ 00067 نقيب
  - D06071「نائب في الخطابة」→ Q932945 خطيب
  - D07144「نائب شيخ الخانقاه الناصرية بسرياقوس」→ Q7492880
  - D07863「أحد مؤذنيها نيابة」→ Q239718 مؤذن
  - D07962「ناب في إمرة مكة」→ 00163
  - D07095「خلفه في جهاته بجامع القلعة بل نيابة」→ #NEEDID
（「نائب الشام」などの総督、「نائب القلعة」は代理職ではないので対象外。）

- **(a)** 代理ごとに専用 ID を発行する（既存の 00207・00285 などに合わせる）。新しい ID が 7 つ前後必要で、本職ごとに増え続ける。
- **(b) 推奨**: 代理は **本職の ID＋`<state type="office" subtype="deputy">`**（TEI の state は @subtype を持てる。repo では未使用の属性）。職位は「本職 ID＋場所・施設＋deputy」で識別する。既存の代理専用 ID のうち、**制度として独立した職**である نائب الحكم（00096、副カーディーの任命制度）と نائب كاتب السر（00244）は固有 ID のまま残す。00207・00285・00318・00125 は本職 ID＋deputy に付け替えて retired（00285 は PR #108 で汎用 ID にしたが、(b) ではこれも Q125482＋deputy にする）。
- (c) 現状のまま、ラベルだけで区別する（評価・検索で代理と本職を区別できない）。

(b) を採る場合は、規則65 に (f)「代理は本職 ID＋subtype="deputy"。ただし نائب الحكم・نائب كاتب السر は固有 ID」を追記し、アプリ（解析プロンプトと XML 出力）にも deputy の欄を足す。機械学習チームには「官職は ID＋場所・施設＋deputy の組で照合」と伝える。
