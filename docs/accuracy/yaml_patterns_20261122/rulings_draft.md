## 検出規則への反映
- P6 は典拠（bibls）と本文の語句の違いも比べるようにする（D05997・D06548・D07409 の誤検出を防ぐ）。
- P1b は「ممن」などの「من」を除く。
- P2 で見つかった relation の subtype に統制語彙外のもの（killed together with・advisor/tutor・colleague・host・rival・companion）がある。別途、統制語彙との照合が必要。
