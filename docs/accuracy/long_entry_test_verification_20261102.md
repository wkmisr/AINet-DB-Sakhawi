## 2. Gemini 出力の問題（運用上の要対応順）
1. **女性の sex がすべて M**（女性4項・D13517 の3回すべて）。app.py の性別選択欄 `st.selectbox(key="sex_select")` が新しい解析で初期化されず、同じセッションでは前の値が残る疑いが強い。女性部（D12xxx〜D13xxx）に入る前に直す必要がある。
2. **師・弟子の relation に名前が出ない**ので、#NEEDID だと誰か分からなくなる。
3. **実行ごとの揺れ**（D13517、3回）: 2回目は叔父 relation と没年を落とし、3回目は父を #NEEDID にした。
4. **意味の取り違え**:
   - D13325「وكنت منهم」の話者はイブン・ハジャルなのに、イジャーザの受け手をサハーウィーにした。
   - D13517「ماتت بعد زوجها المتوفي سنة ثلاث وسبعين」を没年873とした（2/3回。正しくは「873年以後」）。
5. **形式の誤り**: 言及を relation（「biographical subject」「other」）で書く、relation 内の @when にヒジュラ年、空の `active=""`、年初が西暦年末にかかる年の1年ずれ（794→1392、765→1364）。
6. **本伝があるのに wd を使う**（D01464 の الجلال البلقيني・ابن ناصر الدين）。ID-Master にその wd 行が登録されているため。
