1047件が同じ形に従っており、**`subtype` は active の役割ではなく「伝主から見た相手方の役割」を表す**規約でした。

- `subtype="teacher"` … 相手方が**伝主の師** → active=相手方(師)／passive=伝主
- `subtype="student"` … 相手方が**伝主の弟子** → active=伝主(師)／passive=相手方

これは標準規則「**active=師／passive=学生**（物理方向）」と完全に両立します。私は「subtype は active の役割を表す」と誤読し、`active=伝主` の relation を `teacher` に書き換えてしまいました。**正しい列から誤りの列へ移してしまった**ことになります。
