# 精度検証フォルダ（2026-09-26 新設）

パイプライン・モデル世代交代による校閲精度の変化を、情報学分野の標準指標（Precision/Recall/F1/Slot Error Rate）で継続的に追跡するためのフォルダ。

## ファイル構成

- `精度指標_定義書_20260926.md` — 指標・タクソノミー・記録ルールの定義書（今後の全バッチに適用）
- `model_accuracy_log.tsv` — バッチ単位の指標ログ（今後、バッチ完了ごとに1行追記していく永続ログ）
- `model_accuracy_findings.tsv` — 指摘単位の詳細ログ（同上）
- `遡及検証データ_B59-93_20260926.tsv` — 2026-09-26時点で、定義書制定前の過去バッチ（B59-63〜B89-93）を遡って手作業で読み解き集計した、H/M/L重大度別件数・100件あたり不備率のスナップショット。研究会向けアーティファクト（校閲精度の推移グラフ）の元データ。

## 過去データは標準指標（P/R/F1）で検証できるか — 結論

**できません。** 少なくともB59-93については、Precision/Recall/F1/Slot Error Rateの算出に必要な分母（正しかった主張数・チェック対象とした主張の総数）が、当時のVERIFY_REPORT等の原資料に記録されていないため、遡って復元できません。

今回集計できたのは以下の代替指標のみです（`遡及検証データ_B59-93_20260926.tsv` の `per_100` 列）:
- **100件あたりの不備件数**（`total_defects / n_entries × 100`）— 「誤りの絶対量」の目安にはなるが、正しかった項目数を分母に含まないため、標準的な意味でのPrecision/Recallとは別物
- H/M/L重大度別の内訳（B64-83, B86-93のみ。B59-63は重大度分類自体が存在しない）

`model_accuracy_log.tsv` の該当行にも `[遡及再構成]` 注記としてこの限界を明記済み。B59-93のP/R/F1列は空欄のままにしてあり、今後もこれらの行を書き換えて数値を埋めることはしない（できないものをできたことにしない）。

**標準指標（P/R/F1/SER）で正式に検証できるのは、定義書制定後の B94 以降のバッチから**です。VERIFY_BRIEF・CHUNK_BRIEF に定義書の記録要件を組み込み、`model_accuracy_log.tsv` / `model_accuracy_findings.tsv` に必要な分母（`n_assertions_checked` 等）を都度記録していけば、B94以降は機械的にP/R/F1/SERを算出できる。

## 今後の定期検証の進め方

1. 毎バッチ完了時に `model_accuracy_log.tsv` / `model_accuracy_findings.tsv` を更新（統一規則24、HANDOVER参照）
2. 数バッチ分たまった時点で、`n_assertions_checked` 等が入っている行（= B94以降）についてP/R/F1/SERを計算し、モデル・pipeline_version別に比較する
3. **pipeline_versionが異なるバッチ同士は単純比較しない**（検証の厳しさ自体が異なるため。定義書§7参照）
