(c) 検証パスで `convertdate`（グレゴリオ暦を返す）を使わないことをブリーフに明記するか。
**暫定判断**: 本バッチ20件は**ユリウス暦で統一済み**（D04420 のみ実値修正、他5件は注記のみ是正）。
**影響**: 全バッチ横断。再換算するなら日精度148件・月精度105件・年精度13件が対象で、`@when` の値が実際に変わるのは日精度全件と月精度105件、年精度13件。

## §D-V2 — `state`／`event` の `placeName` をニスバから補ってよいか
**事実**: B86b は原文に地名がない state/event の placeName を除去（D04450・D04451）、B86a は保持（D04437 の القاهرة、D04435 の تعز）。同一バッチで基準が割れた。
**暫定判断**: 本パスでは**編集せず**現状維持。
**論点**: 「原文にない属性を付けない」を state/event の placeName にも一律適用するか、施設の同定根拠として必要な場合（D04435 の المظفرية＝タイッズ）は許容するか。許容する場合は `cert="low"` の付与を推奨。

## §D-V3 — ja 訳文における بن の転写（「ビン」／「ブン」）
**事実**: B86a は「ビン」、B86b は「ブン」に統一。`Individuals/` 実測は ビン1,940 / ブン2,819。
**暫定判断**: 本パスでは編集せず。
**提案**: 多数派の「ブン」に寄せ、ブリーフの規則6（転写は「イブン・ファハド」式）に「語中の بن は『ブン』」を追記。既存分は一括置換で解消可能。

## §D-V4 — ブリーフ統一規則9の改訂（暦の明示／曜日検算の位置づけ／h2g.py の閏年バグ）
**事実**: (a) 規則9は式のみを示し**暦を明示していない**＝B86a のグレゴリオ換算の直接原因。
(b) 「曜日で検算」は JD 由来のため**両暦で同一**であり、暦の判別材料にならない（両チャンクが検算根拠として誤用）。
(c) `h2g.py` の年末表示は閏年（355日）で1日早い（AH809 の真の年末は 1407-06-07、h2g.py は 1407-06-06）。
**提案**: 規則9を「**ユリウス暦**で換算する（`h2g.py` 準拠。`convertdate` 等グレゴリオ暦を返すライブラリは使用しない）。曜日は tabular 近似の±1〜2日確認にのみ用い、暦の判別には使えない」に改め、h2g.py の年末計算を `jd(y+1,1,1)-1` に修正する。

## §D-V5 — relation の active/passive 方向をブリーフに明記
**事実**: ブリーフは Pattern A について「active=teacher・passive=student」と述べるだけで、**relation 本体の方向規約を明記していない**。
このため B86a は D04428 で `active=学生` という誤ったモデルを適用し、向きを反転させた（[H-2]）。
**実測された規約**: teacher/student relation は **active=師・passive=学生**（`subtype` は本項主から見た記録対象を示すラベル）。
親族・社会関係（father/son/brother/cousin/uncle/patron/friend/spouse/mother/daughter/grandfather）は **active=相手（subtype が指す側）・passive=本項主**（合計1,200件以上で一貫）。
**提案**: この2行をブリーフの統一規則に追加する。

## §D-V6 — 単独人物を特定するニスバ索引項（合同索引でないもの）の直接充当可否 ＝ B86a §D-3 への補強
**事実**: 統一規則11 は「**3人以上を束ねた** AIND-D 項目」を relation に直接充当してはならないと定める。
D12121「الوسيمي … محمد بن أحمد بن أبي بكر بن محمد بن محمود العمري الكاتب」は**単独人物**を特定する索引項であり、規則11の文言には該当しない。
本パスで近似見出し D06631 を実引きし、当該ナサブの独立本伝が corpus に**存在しない**ことを確認した。
**論点**: 単独人物のニスバ索引項に AIND を直接充当してよいか（＝D12121 を採用して TMP-P-NEW86-03 を取り消すか）。
**暫定判断**: 一次校閲の判断（新規 TMP-P 発行）を**そのまま維持**。規則11の文言上は充当可能だが、「本伝なし」の索引項に AIND を与える運用は repo 全体に波及するため裁定を請う。
