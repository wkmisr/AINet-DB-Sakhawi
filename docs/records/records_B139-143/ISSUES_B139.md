# ISSUES_B139 — Waka の裁定が要る項目（B139: AIND-D06382〜D06399・D07387〜D07395、2026-10-26）

## §D139-1 D06387 兄弟「جانم」の同定（#AIND-D02391 cert medium）
- 「كرتباي الأشرفي قايتباي أحد خاصكيته بل قريبه وأخو جانم」。corpus の جانم الأشرفي قايتباي は #AIND-D02391（ابن أخي السلطان、884没、مصلى المؤمنين で葬礼・تربة السلطان の القبة الكبرى に埋葬）と #AIND-D02392（ويعرف بالأشقر、أحد العشرات、882没）の2人。本項主が「قريبه」（スルターンの親族）で、同じ مصلى المؤمني・تربة السلطان に葬られている点は D02391（スルターンの甥）と整合するので D02391 を cert medium で充てた。D02392 の可能性が残るなら relation を possible 扱いに落とすか裁定を。
- 付記: #AIND-D02284（تمراز الشمسي）本文に「انفصل عنها بكرتباي الاشرفي قايتباي」（البحيرة の職の交代、889年ジュマーダー1月以降の文脈）があるが、本項主は889年ムハッラム没なので同一人物とは整合しない → note のみ。

## §D139-2 D06391 主人「فيروز الساقي」の同定（TMP-P-NEW139-03）
- 「وخدم عند فيروز الساقي」。corpus の候補: #AIND-D06196「فيروز الخازنداري الرومي الساقي」（الناصر فرج と共に育ち、814没）と #AIND-D06198「فيروز الرومي الساقي الجاركسي … صار ساقيا في أواخر الأيام الناصرية فرج ثم في الولاية المؤيدية ودام إلى الأيام الأشرفية … مات في شعبان سنة ثمان وأربعين」。本項主は ジャクマク治世（842〜857）没で、若年に仕えたとすれば D06198（814〜841年頃まで ساقي）の方が年代的に自然だが確証なし。規則26・先例 TMP-P-001375 に従い仮番号を発行。裁定: D06198 に cert medium で同定するか、仮番号維持か。
- 付随: 新規 TMP-L-NEW139-01〜03（الخليج الحاكمي・شق الثعبان・قنطرة سنقر）の wd／gn は未確認。

## §D139-3 D06397「تغرى بردى المؤذي نائب حلب」（TMP-P-NEW139-04）の実体
- 原文は「عصى مع تغرى بردى المؤذي نائب حلب في سنة خمس وعشرين」。corpus で「المؤذي」のラカブを持つのは #AIND-D02264「تغرى بردي الرومي البكلمشي ويعرف لأذاه بالمؤذي」（846没）のみだが、本文は「أقام خاملا إلى بعد سنة ثلاث وثلاثين」でアレッポ副官職・825年の反乱に触れない。825年にアレッポで反乱した副官（史料上は تغري بردي المحمودي）に当たる #AIND-D02271「تغرى بردي المحمودي الناصري」（836没）の本文にも反乱の記述は無い。規則25（原文どおり読む）・26 により仮番号を発行し、D02264 への同定（サハーウィーの呼称の混同の可能性）は裁定に委ねる。
