## 0. 裁定と適用した規約

**規約A（＝旧 `tei-encoding-policies.md` の規定）を正とする。親族関係には `@n` を振らない。**

- **親族系 subtype**: `@n` を**付けない**（既存の `@n` は除去）。
- **それ以外の subtype**: **非親族 relation のみを数えた**文書順の連番 `@n`（1 始まり・欠番なし）。
  親族 relation は数に含めず、間に挟まっても番号を消費しない。
- `@n` の挿入位置は既存の優勢な属性順（`type` → `subtype` → `n` → `active` → `passive` → …）に合わせ、
  `subtype` 属性の直後に挿入した。

これにより HANDOVER v13.28 統一規則1（「`<relation>` 全体の出現順通し番号」）は**破棄**される。
次回 HANDOVER の統一規則1 を本規約Aの文言に差し替えること。

> **注記（要確認）**: 裁定の根拠として挙げられた `docs/tei-encoding-policies.md` は、
> 本ブランチの作業ツリー・`git HEAD` のいずれにも**存在せず**、リポジトリ内のどの文書からも参照されていない。
> 本作業は裁定文に記された規約Aの内容そのものに従って実施した。
> 当該ポリシー文書が別管理であれば、規約Aの正文として repo 内に復元することを推奨する。
