# B82 要判断・名寄せ提案・欠番ウォッチ・別名追記（D05150–D05187）

## A. 要判断（Waka 裁定）
1. **D05169 المهمندارية の番号カテゴリ**: ブリーフ対応表は「المهمندارية = TMP-O-00105」だが、TMP-O-00105 は ID-Master 上 Office（mihmandār 職、D02056/D02051 の「ولي المهمندارية」）。D05169「كان يدرس بالمهمندارية」はカイロのマドラサ（D00143「بالمهمندارية بالقرب من جامع المارداني」、D05040「تدريس المهمندارية」、D07173「مشيخة المهمندارية وتدريسها」）で、affiliation/orgName 位置に O 番号はカテゴリ違反（precheck も指摘）。→ 新規 Institution **TMP-I-00155** を発行して置換。対応表どおり O-00105 を使うべきなら差し戻し要。
2. **D05150 父 ريحان → #AIND-D03027（cert medium）**: 本項主のニスバ「العيني」が corpus 中 D03027「ريحان الحبشي المكي ويعرف بالعيني」の通称のみに対応し、D05151（التعكري ＝ D03021 の子）と同型の「父の通称継承」。ただし D03027 側に子の言及なし。cert medium で採用したが、#NEEDID 維持が望ましければ差し戻し。
3. **D05170 死没「سنة خمس أو قريبا منها」**: repo D04304 の前例に従い when-custom="0805" cert="medium" とした。規約7「قريب」を notBefore/notAfter 方式で統一するなら 0803–0807 等に変更要（D05187「قريب التسعين」は notBefore/notAfter 0888–0892 方式を採用、幅±2は校閲者解釈）。
4. **D05179 見出し「علي بن شكر الحسني حسن بن عجلان المكي」**: 底本の脱字（「عتيق」等）と思われ、父項 D03328「الحسني عتيق السيد حسن بن عجلان」に照らして主従由来のニスバと解した。حسن بن عجلان（#AIND-D02560）への patron/client relation は本項主自身の主従関係が原文に明示されないため立てていない。nisbah ref TMP-N-00079（الحسني）は綴り一致で付与したが、血縁のハサン裔ではない点に注意。
5. **D05183 event type="other" の運用**: 「الجوهري نسبة لمولى لهم ممن كان يخدم القاضي أبا السعادات بن ظهيرة」を relation にせず event other（persName #AIND-D09082）で保持した。prose のみに留める方針なら削除可。
6. **D05155 relative（cert medium）→ #AIND-D10946**: 「رئيس المؤذنين بمكة」は無名だが、882年当時の在職者は D10946（857–889）で一意、兄項 D07407「قريب الرئيس محمد بن أبي الخير」・索引 D12335 で裏付け。無名官職者への relation を避ける方針なら event 化に差し戻し。

- **TMP-P-000863（محمد بن أبي الخير … رئيس المؤذنين بالمسجد الحرام）** は D10946 の父。D10946 本伝に「ولي رياسة المؤذنين بعد والده … في سنة سبع وخمسين」＝ 857 年没とみられる旨を Note に追記提案。
