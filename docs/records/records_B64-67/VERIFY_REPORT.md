### L-1. 規約⑤の適用漏れ（西暦併記なし）が 22 箇所
`notBefore-custom` / `notAfter-custom` / event の `when-custom` に対応する西暦属性がない。death/birth の `when-custom` にはすべて `when` が併記されており、扱いが不統一。

→ 一括で西暦を補完するか、「日付要素以外は西暦併記を要しない」と規約側で明文化。確信度 **L**
