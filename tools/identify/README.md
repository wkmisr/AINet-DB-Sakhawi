# tools/identify — 同定の道具（設計書 第5版 第4.2節）

モデルが同定のときに使う検索の道具。結果はレコードに書き戻さない。

| 道具（4.2節） | コマンド |
|---|---|
| 1 名前の検索 | `idtool.py search "الشرف بن مفلح"` |
| 2 系譜のずらし | `idtool.py genealogy AIND-D01906 father`（father, son, brother, grandfather, paternal_uncle, cousin, siblings_child など） |
| 3 逆引き | `idtool.py reverse AIND-D04627`（XMLの参照、本文中の「ابن X」形の言及） |
| 4 隣接する伝記 | `idtool.py neighbours AIND-D10588 -n 2` |
| 5 伝記の閲覧 | `idtool.py read AIND-D10588` |
| 6 典拠表の検索 | `idtool.py authority "ابن الجزري"`（TMP-P と Wikidata の人物。`authority/persons_registry.tsv` がなければ PR #120 のブランチから読む） |
| 事前検索（1＋2＋「الذي قبله」） | `idtool.py search "حفيد الذي قبله" --record AIND-D10588 [--kind brother]` |

出力は1行1件の JSON。`features AIND-Dxxxxx` で、見出しから取り出した名前要素を確認できる。

## 名前の扱い（検索用だけ）

- 正規化：OpenITI の normalize_ara_light（`tools/viewer/to_v01.py` と同じ）に、母音記号・タトウィール・ター・マルブータ（ة→ه）・五名詞（أبي→أبو）を加えたもの。
- 見出しから、ism（I）、父（F）、祖父（G）、それより上（P）、ラカブ（L：`الشرف` と `شرف الدين` を同じ語幹に）、祖先のラカブ（FL：`بن الشرف`）、クンヤ（K）、ニスバ（N）、通称（A：`ويعرف بابن X`）を取り出す。
- 系譜（nasab）は本文の順。`بن الكمال أبي الفضل محمد` はラカブとクンヤを飛ばして `محمد` を取る。ラカブしかない祖先は `L:شرف` と書く。
- 見出しの名前の範囲は、最初の「،」「.」か「ولد」「مات」などの語まで。

- 2026-11-24 の粗い試作（1位 9.6%、100位以内 63.1%、3,365件）とは、件数の数え方が違う（今回は記録・相手・語句の組で重複を除いた）。
