# tools/identify — 同定の道具（設計書 第5版 第4.2節）

モデルが同定のときに使う検索の道具。結果はレコードに書き戻さない。

| 道具（4.2節） | コマンド |
|---|---|
| 1 名前の検索 | `idtool.py search "الشرف المناوي"` |
| 2 系譜のずらし | `idtool.py genealogy AIND-D06528 father`（father, son, brother, grandfather, paternal_uncle, cousin, siblings_child など） |
| 3 逆引き | `idtool.py reverse AIND-D04627`（XMLの参照、本文中の「ابن X」形の言及） |
| 4 隣接する伝記 | `idtool.py neighbours AIND-D06501 -n 2` |
| 5 伝記の閲覧 | `idtool.py read AIND-D06501` |
| 6 典拠表の検索 | `idtool.py authority "ابن الجزري"`（TMP-P と Wikidata の人物。`--all` で伝記のある人物の別名も引く。典拠表の注記も返す。読み先は main の `authority/persons_registry.tsv`） |
| 全文の検索（2026-11-29 追加） | `idtool.py text "بابن حسان" ["二つ目の語句" …]`（すべての語句を本文に含む項。通称が見出しの外にしか出ない人物を探す。指針 6.3 の `text`） |
| 事前検索（1＋2＋「الذي قبله」） | `idtool.py search "أخو الذي قبله" --record AIND-D06501 [--kind brother]` |

出力は1行1件の JSON。`features AIND-Dxxxxx` で、見出しから取り出した名前要素を確認できる。転送の見出し・統合済みの番号は、結果に `status` と `target`（転送先・統合先）が付く（2026-11-29 追加）。

## 指針と指示文（2026-11-29）

- **指針（正本、英語）**：`docs/guidelines/identification.md`。判定の種類、証拠の基準、検索の手順、サハーウィーの言い回しの読み方、回答の形式、検証の手順。
- **指示文（指針の抜粋）**：`tools/identify/prompts/`

| ファイル | 中身 |
|---|---|
| `identify.system.md` | 同定の指示文（三社共通）。`{{MAX_CALLS}}` に追加の検索の上限、`{{CONVENTIONS}}` に `conventions.md` を入れる |
| `identify.user.template.md` | 1伝ごとの入力の形（見出し、前後の見出し、言及に印を付けた本文、言及の一覧、事前検索の結果、逆引き） |
| `conventions.md` | 取り決め集。読んだだけでは決まらない呼び名についての裁定（ابن فهد の振り分け、同名の人物など）。裁定が増えたらここに足す |
| `tools.json` | 道具の定義（三社の関数呼び出しの形式に変換する元）。`search_names`→`search`、`search_text`→`text`、`authority` の `include_entries`→`--all`、`kin`→`--kind` |
| `output.schema.json` | 回答の形式（JSON Schema）。採点スクリプトはこの形を読む |
| `verify_choice.system.md`・`verify_choice.user.template.md`・`verify_choice.schema.json` | 検証（主担当が「同定」とした言及）。結論を隠して候補から選ばせる。使える道具は `read` と `neighbours` だけ |

主担当が「見つからない」「対象外」とした言及の検証は、`identify.system.md` をそのまま使って検証役に探し直させる（設計書 4.4節）。

指示文の例には、試行の10伝（`AIND_gold10_form`）の本文を使っていない。指針と指示文を書くときにも、10伝は見出しのほかは読んでいない（取り決め集の語が10伝に出るかどうかだけを機械で確かめた）。この README の例も10伝以外に替えた。

まだないもの：三社を呼ぶ実行スクリプト（入力の組み立て、道具の呼び出しの記録、上限の管理）、採点スクリプト、対象外の一覧。


## 名前の扱い（検索用だけ）

- 正規化：OpenITI の normalize_ara_light（`tools/viewer/to_v01.py` と同じ）に、母音記号・タトウィール・ター・マルブータ（ة→ه）・五名詞（أبي→أبو）を加えたもの。
- 見出しから、ism（I）、父（F）、祖父（G）、それより上（P）、ラカブ（L：`الشرف` と `شرف الدين` を同じ語幹に）、祖先のラカブ（FL：`بن الشرف`）、クンヤ（K）、ニスバ（N）、通称（A：`ويعرف بابن X`）を取り出す。
- 系譜（nasab）は本文の順。`بن الكمال أبي الفضل محمد` はラカブとクンヤを飛ばして `محمد` を取る。ラカブしかない祖先は `L:شرف` と書く。
- 見出しの名前の範囲は、最初の「،」「.」か「ولد」「مات」などの語まで。

- 2026-11-24 の粗い試作（1位 9.6%、100位以内 63.1%、3,365件）とは、件数の数え方が違う（今回は記録・相手・語句の組で重複を除いた）。

- 親族の語に名前が付いている言及（「والد الشهاب أحمد الماضي」）で、系譜のずらしと名前の一致を掛け合わせていない。AIND-D08057 の子（AIND-D01411）は事前検索の上位に出ず、系譜の全体で引き直すと1位に出る（2026-11-29 の試し読み）。順位付けの改良の候補。
- 規則は同じ正解を見ながら調整したので、数値はやや甘い。試行の10伝（未処理）で測り直す。
- ラベル型の `<desc>` は名前を含まないので、この方法では測れない（本番では本文の語句を渡す）。
- 測定項目11（事前の検索の時点で正解が候補に入っていた割合）は、試行ではこのスクリプトの事前検索で測る。
